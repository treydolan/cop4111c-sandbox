Divide

The divide classes allow you to easily set up borders between elements

Divide Width

divide(-DIR)(-AMT)

SID
  • x
  • y
AMT(divide)
  • 0
  • 2
  • 4
  • 8
  • reverse

Example:

  • Fred
    Rivet
    Eileen
    Belle
    Cosmo
    Dolly
    border: VARIED
    divide-(DIR)(-STR)
    DIR
    x y
    STR
    0 2 4 8 reverse

Divide Color

The border colors just as you'd expect are trasnparent, black white and current...which sets the color to whatever the current color is set to. Plus the traditional gray, red, yellow, etc. and the strengths go from 100 to 900.

divide-COL-STR

Example:

  • Fred Rivet Eileen
    Fred Rivet Eileen
    Fred Rivet Eileen
    Fred Rivet Eileen

    Fred Rivet Eileen
    divide-COL-STR
    COL
    transparent current black
    white gray red
    yellow green blue
    indigo purple pink
    STR
    100 200 300
    400 500 600
    700 800 900
