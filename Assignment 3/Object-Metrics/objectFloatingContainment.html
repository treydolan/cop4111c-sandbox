Object Fit

object-(SID)

DIR
  • contain
  • cover
  • fill
  • none
  • scale-down

Object fit controls how an element is stretched to fit it's container. It's similar to what you'd expect when using background images.

Example:

  • object-contain
  • object-cover
  • object-fill
  • object-none
  • object-scale-down

  • left
  • center
  • right

  • bottom

  • object-center
  • object-right
  • object-left-bottom
  • object-bottom
  • object-right-bottom
