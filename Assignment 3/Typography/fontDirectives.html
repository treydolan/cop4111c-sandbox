Font Directives

There are two types of typogrophy classes, let's take a look at the types that are related to fonts

Font Family

  • font-sans
  • font-serif
  • font-mono
                    theme: {
                        fontFamily: {
                            'sans': ['Helvetica', 'Arial', 'sans-serif'],
                            'display': ['Custom Font', 'Other Font'],
                        }
                    }

There are three different classes that you can use to specify what type of font you want to use in a project.

The font-sans style is already applied to page by default. By default, it will try to apply default system fonts for the styles, but you can pverrode any of the default families by modifying the theme.fontFamily element in tailwind.config.js

You can even create a new font by adding one or more elements to that object.

Font Size

SIZ (font-size/line-height...in rems)
  • xs .75/1
  • sm .875/1.25
  • base 1/1.5
  • lg 1.125/1.75
  • xl 1.25/1.75
  • 2xl 1.5/2
  • 3xl 1.875/2.25
  • 4xl 2.25/2.5
  • 5xl 3/1
  • 6xl 3.75/1
  • 7xl 4.5/1
  • 8xl 6/1
  • 9xl 8/1

Font size is handled through the text class and you add a size option here.

This changes two parameters at the same time (fontsize and line-height)

Rem is relative to the root size of the browser, which is usually 16 pixels

Font Weight

font-WGT WGT (font-weight)
  • thin 100
  • extralight 200
  • light 300
  • normal 400
  • medium 500
  • semibold 600
  • bold 700
  • extrabold 800
  • black 900

Font weight is handled through of a series of named classes starting with the font keyword.

Some fonts will contain only specific weights

Font Style

  • italic
  • non-italic

Only two styles you can modify under font style, whether an item is italic or not.

non-italic sets font-style to normal and it's obviously for changing things that would normally be bold, like headlines to not display as bold.

Font Smoothing

  • antialiased
  • subpixel-antialiased

There are two different types of font smoothing you can use. The default is called subpixel antialiased, if you want to switch you simply add the aliased keyword and to override it, you use subpixel-antialiased.

Font Variant Numeric

  • normal-nums
  • ordinal
  • slashed-zero
  • lining-nums
  • oldstyle-nums
  • proportional-nums
  • tabular-nums
  • diagonal-fractions
  • stacked-fractions

For controlling advanced styles for fonts.

The important thing to know is that not all fonts support these features and as a matter of fact most Google Fonts, even ones that point to fonts that would normally support these features will work.

It needs to be an OpenType font
