Alpine.js features used:

x-data — reactive state management (tasks, filters, counters)
x-model — two-way binding on the input and select
x-for — looping through filtered tasks
x-show — showing/hiding the empty state
x-text — dynamic text rendering
:class / :style — dynamic class and style bindings
@click / @keydown.enter — event handling
